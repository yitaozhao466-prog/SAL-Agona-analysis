# SAL-Agona-analysis
This repository contains comprehensive genomic analysis of Salmonella enterica    serovar Agona (SAL_Agona) isolates, including phylogenetic reconstruction,    strain clustering, and molecular epidemiological characterization.  
# SAL_Agona Genomic Analysis

## Overview
Genomic analysis pipeline for SAL_Agona strains.

## Structure
- `data/`: Raw data
- `script/`: Analysis and visualization scripts

## Usage
Prepare data in the `data/` directory and run scripts in the `script/` directory.

## Requirements
MAFFT, IQ-TREE, BLAST, R
